# MCQuiz

객관식(4지·5지선다) 문제 파일을 올리면 바로 풀 수 있는 퀴즈 웹앱입니다. 한 문제씩 풀고 즉시 정답과 해설을 확인하며, 틀린 문제와 헷갈린 문제를 모아 다시 풉니다.

## 기능

**문제 넣기 (관리자)**
- JSON(권장), "문제지 + 정답·해설" 텍스트, 번호만 적힌 복기 메모(`1 `, `1)`, `①`, `(1)` 모두 인식), PDF를 올리면 퀴즈로 바뀝니다. 줄바꿈이 깨진 텍스트도 번호 패턴으로 다시 나눕니다.
- 미리보기에서 정답·해설·단원을 고친 뒤 저장. 같은 (주제, 단원, 질문) 문항을 다시 올리면 중복 없이 덮어씁니다. 검증에 실패한 문항은 목록으로 보여 주고 나머지는 저장합니다.
- 문항 메타: 세부 주제(`topic`), 난이도(`difficulty`), 배점(`points`), 함정 유형(`trap_types`), 근거 문장·쪽수(`source_quote`, `source_page`), 문항 해설(`explanation`)과 선지별 해설.
- 단원 자동 배정: 원문 표시(`[26강]`, `unit_no`) → 키워드 매칭(Postgres 전문검색) → (선택) AI 순.
- 폴더째 일괄 업로드 CLI: `npm run import:questions -- <폴더>`.

**근거 자료 (관리자)**
- 강의 스크립트·노트·책(txt/md/pdf)을 올리면 단원에 연결되고, 검색용 조각으로 나뉩니다. 책은 `[p.N]` 표시 기준으로 쪽 단위, 쪽수가 보존됩니다. 목차 파일로 단원을 일괄 생성합니다.
- 문항마다 "근거 찾기": 그 문항의 단원 자료(스크립트+책)에서 먼저 찾고, 없을 때만 전체에서 찾습니다. 출처는 "N강 스크립트", "책 p.N"으로 표시됩니다.
- AI에게 묻기(선택, OpenAI 키 필요): 찾은 자료만 근거로 답하고 출처를 붙입니다. 새 탭으로 열려 풀던 퀴즈가 끊기지 않습니다.

**퀴즈**
- 시작 화면: 주제 → 단원 트리(상위를 고르면 하위 포함, 여러 개 동시 선택) / 묶음 / 세트. 문항 수 10·20·40·전체, 순서대로·무작위, 난이도(하/중/상/최상) 선택, 많으면 "1~10번, 11~20번" 구간으로 나눠 풀기.
- 한 문제씩 풀고 즉시 채점. 선지는 섞이지만 해설은 선지에 붙어 함께 이동. 답을 고르면 정답/오답 → 문항 해설 → 선지별 해설 → 근거(책 p.N) → 함정 유형 배지 순으로 보입니다.
- 힌트, 헷갈림 체크, 직접 "저장", 플래시카드 모드, 문항별 메모(자동 저장).
- 진행 상태가 서버에 저장되어 뒤로가기·새로고침·다른 기기에서도 풀던 문항부터 이어집니다("이어서 풀기").
- 결과: 배점 합산 점수, 틀린 문항·헷갈린 문항 요약, "틀린 것만 다시 풀기", "묶음에 추가".

**저장함**
- 틀린 문항과 헷갈림 체크한 문항이 자동으로 모이고, 직접 "저장"한 문항도 들어옵니다. 각 문항에 틀린 횟수·최근 결과 배지.
- 주제 → 단원 순으로 골라 보거나 전체 보기. 문항은 "1강 7번"처럼 단원·번호로 표시.
- "빼기"로 목록에서 제외(다시 틀리면 자동 복귀). 틀림/헷갈림/직접 저장 필터, 이 목록 풀기, 묶음에 추가.
- 통계: 단원·세부 주제·난이도·함정 유형·세트·태그별 정답률과 약점 횟수. "약점 섞어 풀기"는 약한 영역의 새 문항 60% + 저장된 문항 40%.

**필기**
- 문제를 풀며 쓴 메모가 주제 → 단원별로 누적됩니다. 바로 수정(자동 저장), 글자 크기 조절(A−/A+), "해설·근거 가져오기"로 문항 해설과 근거를 메모에 붙일 수 있습니다.

**묶음(collections)**
- 단원과 별개로 문제를 모아 두는 트리. 공용 묶음(관리자)과 개인 묶음. 묶음 단위로 풀기, 문항 빼기.

**계정·권한**
- 이메일+비밀번호 또는 이메일 링크(비밀번호 없이) 로그인. 계정 화면에서 비밀번호 설정.
- 주제마다 `public`(로그인한 모두) / `restricted`(허용된 사용자만). 권한은 Postgres RLS로 강제되어 API로도 우회할 수 없습니다.
- 관리자 화면(`/admin`): 주제 생성, 사용자 권한 부여·회수, 단원 트리 편집(번호 범위 일괄 생성), 자료 업로드, 문제 업로드, 세트 편집.

## 스택

Next.js 16 (App Router, TypeScript) · Tailwind CSS v4 · Supabase (Auth, Postgres, RLS) · Vercel · OpenAI(선택)

## 시작하기

```bash
npm install
cp .env.example .env.local      # 값 채우기
npm run db:start                # 로컬 Supabase (Docker 필요) — 또는 원격 프로젝트 사용
npm run dev
```

### 환경변수

| 이름 | 설명 |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase 프로젝트 URL |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon(publishable) 키 |
| `SUPABASE_SERVICE_ROLE_KEY` | 서버 전용. 관리자 플래그, 로컬 스크립트에 사용 |
| `ADMIN_EMAIL` | 이 이메일로 로그인하면 자동으로 관리자 |
| `PUBLIC_GUEST_ACCESS` | `true`면 비로그인 방문자도 공개 주제를 풀 수 있음(기록은 저장되지 않음). 기본 `false` |
| `OPENAI_API_KEY` | 선택. 규칙 파서가 실패한 텍스트의 AI 파싱, 단원 분류 보조 |
| `OPENAI_MODEL` | 선택. 기본 `gpt-6-luna` |

`.env*` 와 `content/` 는 git 에 올라가지 않습니다.

### 원격 Supabase 에 스키마 적용

```bash
supabase login
supabase link --project-ref <ref>
npm run db:push
```

### 첫 설정 순서

1. 회원가입 후 `ADMIN_EMAIL` 계정으로 로그인하면 `/admin` 메뉴가 열립니다.
2. `/admin` 에서 주제를 만들고, 제한 주제라면 이메일로 사용자에게 권한을 줍니다.
3. `/admin/sources` 에서 목차 파일과 스크립트를 올리거나, 로컬에서 일괄 업로드합니다.
   ```bash
   npm run upload:sources -- "<주제 이름>" content/sources
   ```
4. `/admin/upload` 에서 문제 파일을 올리거나 텍스트를 붙여 넣고 미리보기에서 확인 후 저장합니다. CLI 도 있습니다.
   ```bash
   npm run upload:questions -- "<주제 이름>" content/questions/문제.txt content/questions/정답.txt
   ```

## 지원하는 문제 형식

**JSON**
```json
[{ "prompt": "질문", "choice_count": 4, "correct_choice": 2, "unit_no": 3,
   "choices": [{ "ord": 1, "text": "…", "explanation": null }, { "ord": 2, "text": "…", "explanation": "정답 이유" }] }]
```

**문제지 + 정답·해설**
```
1. 질문
1) 선지
2) 선지
3) 선지
4) 선지
```
```
1. 정답: 2번
  1) 틀림. 이유
  2) 옳음. 이유
```

**복기 메모** (정답·해설 없어도 됨. 저장 후 미리보기나 세트 화면에서 정답 지정)
```
1. 질문
1 선지
2 선지
3 선지
4 선지
```

AI 에게 문제를 만들게 할 때 쓰는 프롬프트는 [docs/quiz-prompt.md](docs/quiz-prompt.md) 에 있습니다.
